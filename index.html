All The Mods 10 — eggplays edition

A private modded Minecraft server. Follow the steps below to join.

⬇ Download Modpack (.mrpack)

Step 1 — Install Tailscale

Tailscale creates a private network between you and the server. You must be connected any time you want to play.

macOS

  1. Download and install Tailscale for macOS.
  2. Open Tailscale from your Applications folder and sign in with any supported provider (Google, GitHub, Microsoft, etc.).
  3. Send your Tailscale login email to the server admin to be added to the network.
  4. Once added, the Tailscale icon in your menu bar will show a green dot — you're connected.

Windows

  1. Download and install Tailscale for Windows.
  2. Open Tailscale from the system tray and sign in with any supported provider (Google, GitHub, Microsoft, etc.).
  3. Send your Tailscale login email to the server admin to be added to the network.
  4. Once added, the Tailscale icon in your system tray will show as connected.

Step 2 — Install the Modpack

  1. Download and install the Modrinth App.
  2. Use the Download Modpack button above to get the .mrpack file, then open it in the Modrinth App to install.
  3. Click Play to launch the modded client.

Step 3 — Connect to the Server

  1. From the Minecraft main menu, click Multiplayer → Add Server.
  2. Enter the server address: ratchet84.tail3078bf.ts.net
  3. Click Done, then double-click the server to join.
Not seeing the server or getting a connection error? Make sure Tailscale is running and shows as connected before launching Minecraft.

Troubleshooting

"Can't connect" / server times out
Check that Tailscale is running and connected (green icon in menu bar / system tray).
"Incompatible client" or kicked on join
Make sure you are running the modpack from the Modrinth App, not vanilla Minecraft.
Asked to be added to the network
Send your Tailscale account email to the server admin.
